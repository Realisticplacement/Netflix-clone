# Netflix Landing Page

A simple, static Netflix-inspired landing page built with HTML and CSS. It includes a featured header, a horizontally scrollable trending titles section, membership benefit cards, frequently asked questions, and footer links.

## Project files

- `index.html` — Page content and layout.
- `style.css` — Styling, responsive layouts, and FAQ presentation.
- `images/header.jpg` — Background image used in the page header.

## Run locally

Open `index.html` in a web browser. No installation, build step, or server is required.

Some trending title images are loaded from external URLs, so an internet connection is needed to display them. The email fields and “Get Started” buttons are visual elements only and do not submit a signup.
